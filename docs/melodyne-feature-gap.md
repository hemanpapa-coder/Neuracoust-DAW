# 내장 피치 에디터 — 멜로다인 대비 기능 격차 (2026-07-25)

우리 내장 피치 에디터(`PitchEditor.{h,cpp}` + `PitchEditorPanel.swift`)가 이미 가진 것과,
멜로다인(Editor/Studio)에 있으나 우리에게 아직 없는 것을 정리한다. 사용자 우선순위:
"편집 기능이 부실하다" → 편집 인터랙션 강화가 최우선.

## 이미 있는 것 (엔진 `DetectedNote` + 툴)
- 피치 이동 (반음 스냅), 비브라토 깊이(modulationScale), 드리프트(driftScale)
- 포먼트 이동, 노트별 게인 ±24dB, 음소거
- 가로 이동(timeOffset), 길이 스트레치(durationScale 0.25–4×), 어택 속도
- 노트 분리(split), 검출 모드(멜로딕/폴리포닉/퍼커시브), 온셋 검출, YIN 피치 트랙
- 손/돋보기(마퀴 줌) 내비게이션, 실제 파형 블롭, audition, 재생 시 자동 적용

## 없는 것 — 우선순위별

### P0 (편집 부실함 직결 — 먼저)
1. **다중 노트 선택 + 일괄 편집** — 여러 블롭 선택해 함께 이동/음정/레벨/퀀타이즈. 지금은 노트 1개씩만.
2. **스케일/키 스냅** — 편집 가능한 스케일 룰러, 노트를 조(key)에 스냅. (키 검출은 이미 있음 → 연동)
3. **피치 보정 매크로 (Correct Pitch)** — "피치 센터 %" + "드리프트 %" 슬라이더로 원클릭 보정.
4. **자유 피치 커브 편집** — 노트 내부 피치 윤곽을 직접 그리기(현재는 기존 비브라토를 배율로만 조절). 멜로다인의 핵심. 구현 무겁지만 가치 큼.
5. **노트 재지정(assignment) 보정** — 잘못 검출된 음/옥타브를 수동 교정, 노트 병합.

### P1 (타임/음색)
6. **타임 퀀타이즈(그리드 스냅, 강도/그루브)** — 노트를 비트 그리드로, 강도 %.
7. **피치 센터 핸들** — 노트의 중심 음정을 커브와 독립적으로 드래그.
8. **노트 간 전이/글라이드 편집** — 이웃 노트 사이 연결 피치.
9. **노트 내부 타임 핸들** — 노트의 일부만 스트레치.
10. **반음 스냅 켜기/끄기 토글** — 현재는 항상 스냅(연속 이동 불가).

### P2 (레벨/워크플로우)
11. **레벨 균형 매크로(leveling)** — 노트 레벨 자동 균등화.
12. **노트 복사/붙여넣기/복제/이조(transpose)**.
13. **피치 값 표시/정밀 입력**(센트 단위 리드아웃).
14. **커서 위치부터 재생/스크럽**.
15. **노트별 페이드 인/아웃**.

### P3 (멜로다인 Studio 급 — 후순위, 고난도)
16. **사운드 에디터(배음/파셜 개별 편집)** — 매우 복잡.
17. **코드 그리드/코드 트랙 연동**.
18. **멀티트랙 동시 편집 / 레퍼런스 트랙**.
19. **템포 검출 + 템포 맵 편집**.

## 별건 (피치 에디터 밖)
- **ARA 멜로다인이 열리나 작동 안 함** — `AraHost`/`nc_ara_*`는 있으나 바인딩/분석이 미완. 진단 필요.
- **인서트로 멜로다인(큐베이스 Extensions식)** — 내부는 ARA. "확장 슬롯" UI 추가 검토.
