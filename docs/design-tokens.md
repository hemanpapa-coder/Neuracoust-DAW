# 디자인 토큰 (Design Tokens)

출처: `design/Neuracoust DAW v2.dc.html` (Claude Design, 프로젝트 "Pro Tools 스타일 DAW 디자인")
작성: 2026-07-10

> **핵심 사실 1** — 디자인 파일에는 CSS 커스텀 프로퍼티가 **없다**. 모든 값이 인라인 리터럴이다.
> 아래 표가 그 리터럴을 역추출한 것이며, 네이티브 토큰 레이어의 단일 출처가 된다.
>
> **핵심 사실 2** — v2 는 v1 의 **순수 리스킨**이다. 1,360줄 중 538줄이 바뀌었고 전부 인라인 스타일이다.
> 컴포넌트·레이아웃·상태 모델·문구는 완전히 동일하다. 차가운 슬레이트 → 따뜻한 우드 톤, 폰트 교체.
>
> **핵심 사실 3** — 기존 `DawWindowController.mm` 의 `nc*()` 테마 헬퍼는 **v1 팔레트와 값이 일치한다.**
> 즉 기존 UI 는 이미 v1 디자인대로 지어져 있었다. 새 UI 는 같은 토큰 이름에 v2 값을 넣으면 된다.

## §3. 간격 / 반경 / 타이포그래피

### 간격
기본 단위 **4px**, 밀도 높음 (프로 오디오 콘솔). 고정 아트보드 **1920×1180**.

- gap: `2, 3, 4, 5, 6, 7, 8, 12, 14` px (가장 흔함: `3 / 4 / 8`)
- padding: `6px`, `6px 8px`, `6px 9px`, `5px`, `5px 7px`, `5px 14px`, `9px 14px`, `10px`, `10px 14px`, `12px`, `0 14px`, `0 16px`

### 반경

| 값 | 용도 |
|---|---|
| `1px` | 미터 셀 |
| `2px` | 태그, 미터 채움 |
| `3px` | 작은 필/입력/트랙 버튼 |
| `4px` | 클립, 그리드 칩 |
| `5px` | 표준 버튼 |
| `6px` | 표시창, 모듈 행, 검색창 |
| `7px` | 모니터 카드 |
| `8px` | 패널, 드롭다운, 뷰 탭 컨테이너, 비디오 참조 |
| `9 / 10 / 12px` | 큰 카드 |
| `12px` | 플러그인 모달, 채팅 |
| `50%` | 노브, 점, 신호등, 팬 핸들 |
| `10px` | 루트 윈도우 |

### 타이포그래피

- **UI 폰트:** `Space Grotesk` (400/500/600/700) — 폴백 `-apple-system, 'Helvetica Neue', sans-serif`
  - v1 은 `Inter` 였다. **v2 에서 교체됨.**
- **고정폭 폰트:** `IBM Plex Mono` (400/500/600) — 모든 수치/기술 표시에 사용:
  타임코드, 템포, 미터 눈금, dB 값, IP, peak/GR/DSP 통계
- **크기(px):** `6, 6.5, 7, 7.5, 8, 8.5, 9, 9.5, 10, 10.5, 11, 12, 12.5, 13, 14, 16, 20`
  - 본문 UI: **8–11px** / 큰 표시: **16px** (템포·박자), **20px** (마디\|박, 타임코드) / 모달 제목: **14px**
- **굵기:** 400 기본, 500, **600** (대부분의 제목·값), **700** (스트립 이름판, 폴더명, 패널 제목)
- **행간:** 큰 표시 `1.05`, 마스터 아웃 라벨 `1.5`
- **자간:** 라벨 `.2–.6px`, "VIDEO REF" 워터마크 `1px`. 대문자 라벨은 `text-transform: uppercase` + `letter-spacing: .5–.6px`

```css
background:
  radial-gradient(circle at 50% 28%, rgba(255,255,255,.22), rgba(255,255,255,.03) 46%, rgba(0,0,0,.45) 100%),
```

모니터 레벨 노브: `radial-gradient(circle at 50% 36%, #564a3e, #221e1a)`

### 고도 (그림자)
| 대상 | 값 |
|---|---|
| 모달 | `0 40px 120px rgba(0,0,0,.7)` |
| 채팅 | `0 24px 60px rgba(0,0,0,.6)` |
| 컨텍스트 메뉴 | `0 14px 34px rgba(0,0,0,.6)` |

| 카드 | `0 2px 6px rgba(0,0,0,.3)` |

### 기타
- 버튼 상단 하이라이트: `inset 0 1px 0 rgba(255,255,255,.06)`
- 리세스된 표시창: `inset 0 1px 3px rgba(0,0,0,.6)`
- 비디오 프레임 해치: `repeating-linear-gradient(45deg, #2a2d36, #2a2d36 5px, #23262e 5px, #23262e 10px)`
- 헤어라인 테두리: `1px solid #1b1611` 또는 `#0b0806`
- 인서트 체인 행 좌측 색 띠: `border-left: 3px solid {trackColor}`
- 폴더 태그 칩: `{color}22` (13% 알파) 채움
- 깜빡임: `@keyframes ncblink { 0%,100% { opacity:1 } 50% { opacity:.35 } }` (읽지 않은 채팅 벨)

## §5. 화면 구조

고정 `1920×1180` 창. `state.view` 로 Edit / Mix 를 전환하고, **모니터 독은 항상 표시**된다.

```
┌─ 타이틀바 ────────────────────────────────────────────────────┐
│ 신호등 · Neuracoust DAW · v260709 · Midnight Session.ndaw ●   │
│                                    ● CoreAudio · 48.0k · 128  │
├─ 트랜스포트 (2단) ────────────────────────────────────────────┤
│ 1행: 트랜스포트 6버튼 · Loop/Click/Snap · 마디|박 · 타임코드   │
│      · 템포/박자 포드 · MASTER OUT 미터 · [Edit|Mix] 뷰 탭    │
│ 2행: DSP·PDC·IN·PLAY 레이턴시 · CPU 바 · ◆MONITOR DSP        │
│      · ◇REMOTE CORE · [플러그인/인서트]                       │
├──────────────────────────────────┬────────────────────────────┤
│  Edit 뷰  또는  Mix 뷰            │  모니터 독 (392px, 상시)   │
└──────────────────────────────────┴────────────────────────────┘
```

### Edit 뷰
- **툴 레일** 44px, 도구 버튼 8개
- **타임라인**: 플로팅 비디오 참조 PIP(타임코드·뮤트·잠금); 룰러 —
  좌측 **576px 레인 헤더 존**이 `GRID / 인서트 A-E / 인서트 F-J / 센드 A-E / I/O` 로 컬럼 분할;
  마디 눈금, 루프 구간, Verse/Chorus 마커, 빨간 플레이헤드
- **트랙 레인** 3종:
  - 비디오 레인 (필름스트립 프레임)
  - 폴더 행 (라우팅/기본, 셰브런, DSP 칩)
  - 트랙 행 — Pro Tools 스타일 헤더: 색 띠 · 이름+태그 · Rec/Input/Solo/Mute ·
    트랙뷰 &amp; 오토모드 드롭다운 · DSP 칩 · 미니 미터 ·
    인서트 A-E · 인서트 F-J · 샌드 A-E · I/O (출력 + vol/pan)
  - 레인 내용: 그리드선, 클립(SVG 파형 **또는** MIDI 노트 블록), 플레이헤드
- 하단 "＋ 트랙 추가"

### Mix 뷰 (Edit 와 상호 배타)
- 믹스 툴바("믹서" + 표시 토글), 앰버 **라우팅 경고 배너**
- **채널 스트립**을 폴더 컬럼으로 묶음. 스트립 구성(위→아래):
  색 헤더 + 종류 라벨 · 인서트 A-E · 샌드 A-E · I/O in/out · Auto+Group ·
  **팬** 슬라이더 · Rec/Input/Solo/Mute ·
  **페이더 영역**(dB 눈금, 물리 노브 캡 + 컬러 LED + 값, L/R 듀얼 미터) ·
  dB 표시 · 다이내믹 셀렉터 · **이름판** · 채널 통계(peak/GR/DSP)
- **마스터 미터 패널** — 세로 세그먼트 L/R 미터 + 눈금, PEAK / OVERS / 미터모드 버튼군, Phase·Overs LED

### 모니터 독 (392px, 상시)
헤더("모니터 스테이션 · 상시 표시" + ⚙) → 모니터 레벨 노브(-6 dB) + 모드 버튼 + Dim/Mono/Talk →
출력 모드 🔊스피커 / 🎧헤드폰 (스피커: A/B/C 레퍼런스 세트[우클릭 편집], 스피커 모델·물리 출력·시뮬 가중치,
스피커 시뮬 셀렉터, 선택적 인서트 체인 / 헤드폰: 가상 스피커·헤드폰 모델 + Sonarworks 보정) →

## §6. 상호작용 (디자인 파일의 JS 에서 읽은 것)

`.dc.html` 은 Claude Design 템플릿이다 — `sc-for` / `sc-if` / `{{ }}` 바인딩을 `Component` 클래스가 구동한다.
`support.js` 는 그 범용 렌더 런타임이며 앱 고유 동작은 없다.

**상태 모델:** `view`(edit/mix), `playing`, `loop`, `click`, `snap`, `pluginOpen`, `selected`(트랙),
`monOut`(spk/hp), `monSetup`, `monSet`(A/B/C), `hpMode`(virt/model), `spkModel`/`spkPhys`/`spkWeight`,
`moctx`(메뉴 열림/카테고리/x/y), `chatOpen`, `chatUnread`, `ctx`(클립 메뉴 열림/cid),
`folders`·`tracks` 배열 (폴더는 `collapsed`/`dsp` 플래그)

**동작:** `toggleLoop`/`toggleClick`/`toggleSnap`, 트랜스포트 재생, 트랙별 `onArm`/`onSolo`/`onMute`,
폴더 `onToggle`(접기)/`onFolderDsp`; 뷰 탭이 `view` 를 설정하고 `isEdit`/`isMix` 로 한 화면만 표시;
클립 우클릭 → 2단 메뉴(hover 로 카테고리 전환, `stop` 으로 배경 닫힘 방지);
모니터 출력 우클릭, A/B/C 세트 우클릭(모델·출력·가중치·룸EQ 편집); `openChat`/`closeChat`,
`chatUnread` 동안 벨 깜빡임

> 드래그는 **시각적 힌트만** 있다. 인서트 체인 행에 `cursor:grab` `⠿` 핸들과 bypass `⏻` 가 보이고,
> 페이더/팬은 계산된 위치(`faderTop`, `panPos`)로 렌더되지만 이 정적 목업에 드래그 물리는 없다.
> 실제 드래그 동작은 `docs/legacy-ui-contract.md` §3.3 의 기존 구현을 참조할 것.
