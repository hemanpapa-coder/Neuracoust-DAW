# 오디오 인터페이스 D/A 모델러 자료 패키지

작성일: 2026-07-19 (Asia/Seoul)

## 목적

이 자료는 Neuracoust DAW의 오디오 인터페이스 D/A 모델러를 설계할 때 사용할 조사 기반 카탈로그다. 브랜드와 모델명은 연구·호환성 식별 목적으로만 기록했으며, 제조사의 상표·로고·제품 외관을 복제하기 위한 자료가 아니다.

## 포함 파일

- `audio_interface_catalog.csv`: 300개 이상의 모델/세대를 한 행씩 기록한 주 데이터셋.
- `research_report_ko.md`: 범위, 브랜드별 계보, 데이터 해석법, 구현 권고안.
- `measurement_sources.md`: 독립 실측 데이터의 종류와 확보 우선순위.
- `download_manifest.md`: 조사에 사용한 공식·커뮤니티 출처 분류.
- `claude_handoff.md`: Claude가 데이터베이스 및 DSP 모델을 구현할 때 지켜야 할 규칙.

## CSV 상태값

- `current`: 2026-07-19 기준 제조사 현행 또는 공식 판매 페이지 확인.
- `legacy`: 단종/구세대.
- `current_or_long_running`, `current_or_legacy`: 공식 페이지는 남아 있으나 지역·재고에 따라 상태가 불명확.
- `available`: 독립 측정 결과가 존재한다고 확인한 모델.
- `limited`: 일부 측정 또는 리뷰는 있으나 원시 데이터·조건이 충분하지 않음.
- `not_located`: 이번 조사에서 신뢰할 수 있는 실측을 찾지 못함.

## 중요한 제한

1. 빈 숫자 셀은 0이 아니라 `미공개/미검증`이다.
2. 같은 제품명이라도 하드웨어 revision, 생산 시기, 출력 포트, 레퍼런스 레벨에 따라 D/A가 달라질 수 있다.
3. 제조사 dynamic range와 THD+N은 가중치, 대역폭, 출력 레벨, 부하가 서로 다르므로 단순 순위 비교용이 아니다.
4. YouTube 영상과 포럼 그래프는 존재 여부를 표시했지만, 원시 WAV/APx 프로젝트가 없으면 구현 계수로 바로 사용하면 안 된다.
5. 실제 제품명으로 판매되는 에뮬레이션은 상표·표시광고 검토가 필요하다. 공개 UI에는 중립적인 카테고리명과 사용자 소유 캡처 기반 프로필을 권장한다.

## 다음 단계

1. 우선순위 20개 모델을 실물 확보한다.
2. 동일 Audio Precision 또는 고성능 ADC 체인으로 재측정한다.
3. 측정 환경과 원시 데이터에 SHA-256을 부여한다.
4. 샘플레이트·출력포트·출력레벨·부하별 프로필을 만든다.
5. 측정되지 않은 모델에는 임의의 EQ/새추레이션을 생성하지 않는다.
